# Code of conduct

Ghostty Studio welcomes people with different backgrounds, experience levels, identities, and ways
of working. We want project spaces to stay useful, respectful, and safe.

## Expected behavior

- Be considerate and direct. Critique the work, not the person.
- Assume good intent while respecting stated boundaries.
- Make room for newcomers and explain project-specific context without condescension.
- Keep discussions on topic and accept maintainers' decisions about scope.
- Protect other people's privacy. Never repost local configurations, paths, logs, screenshots, or
  personal details without clear permission.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, sustained disruption, impersonation,
doxxing, and publishing private information are not tolerated. Spam and deliberate attempts to
bypass the project's security or review boundaries are also unacceptable.

## Moderation

Maintainers may edit or remove content, lock discussions, reject contributions, or temporarily or
permanently restrict participation when needed to protect the community. Responses should be
proportionate to the behavior, its impact, and whether it continues after a clear request to stop.

For concerns that can be handled publicly, flag the relevant discussion for a maintainer without
repeating harmful or private material. If a private reporting channel is not shown, use GitHub's
content-reporting tools and do not disclose sensitive details in the repository. Technical security
vulnerabilities follow [SECURITY.md](SECURITY.md).

This code applies to repository discussions, issues, pull requests, reviews, and other spaces where
someone represents the project.
