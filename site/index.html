THE FILE IS THE PRODUCT

A configurator should respect the config you wrote.

Most visual editors regenerate a clean file. Ghostty Studio changes only the settings you review and leaves the rest exactly where you put it.

×Typical generator
# personal notes

- config-file = work.conf

+ background-opacity = 0.88

The setting is right, but the document is no longer yours.

# personal notes
font-family = Berkeley Mono
# keep this for work
config-file = work.conf
+ background-opacity = 0.88

One reviewed change. Everything else remains byte-for-byte familiar.

LOCAL MEANS LOCAL

The safest network request is the one the app never makes.

Ghostty Studio has no account, cloud service, telemetry, or general-purpose network, shell, and filesystem access in its webview.

Read the threat model↗
1

Fixed write targets

Rust binds a fixed write target to the current session. The interface cannot submit an arbitrary path.

2

External-change protection

Revision checks stop a stale draft from overwriting edits made by another process.

3

Validated, atomic writes

Ghostty checks the candidate; Studio snapshots, fsyncs, and replaces the target atomically.

4

Private image handling

Images are bounded, normalized, stripped of metadata, and stored with private permissions.

GOOD TO KNOW

Before you download.

Is this an official Ghostty project?

No. Ghostty Studio is an independent community project and is not affiliated with or endorsed by Ghostty.

Which platforms are supported?

The current preview targets Apple Silicon Macs on macOS 11 or later. Linux and Intel support require their own tested platform contracts before release.

Why does macOS show a first-launch warning?

The preview is ad-hoc signed but not Apple-notarized. The release includes a SHA-256 checksum, and you can build from source.

Why are some Ghostty settings reference-only?

Repeatable, sensitive, and source-dependent settings need specialized write semantics. Studio shows them honestly instead of guessing.
